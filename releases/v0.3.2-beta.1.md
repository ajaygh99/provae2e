# PROVA v0.3.2-beta.1 — Real Device Testing

This beta adds opt-in BrowserStack real-device mobile-web execution while preserving local Playwright emulation as the default.

## Highlights

- Typed device-cloud provider API and BrowserStack W3C connector.
- Real iOS and Android device discovery and execution.
- Bounded sequential/parallel execution controls.
- Screenshot capture plus BrowserStack video and log metadata.
- Credential validation, whitespace normalization, error redaction, and idempotent cleanup.
- Machine-readable evidence manifests and strict session/artifact verification.
- BrowserStack CI setup and troubleshooting documentation.

## Validation

- 50/50 real-device sessions passed: iPhone 14 and Google Pixel 7.
- 50 unique BrowserStack sessions.
- 50 screenshots, 50 video links, and 50 log-link sets verified.
- Evidence workflow: https://github.com/ajaygh99/provae2e/actions/runs/30208768161
- Full backward-compatibility, coverage, Studio, security, build, and smoke gates run again during publication.

## Compatibility

There are no breaking changes. BrowserStack is enabled only with `--device-cloud browserstack`; existing local mobile emulation remains unchanged.
