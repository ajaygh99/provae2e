v0.3.3-beta.1, inserts 1,500 representative browser, API and mobile-web runs,
opens it with the v0.3.4 implementation, and compares stable hashes before and
after reopen. Initialization performs SQLite integrity validation and records
schema version 1 without replacing user data.
