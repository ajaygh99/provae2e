# PROVA v0.3.4-beta.1 — Reliability and Evidence

This beta strengthens installation, repeatability, failure diagnosis, secret
safety, and analytics upgrade behavior without changing default test execution.

## Highlights

- Clean-install and packed-CLI validation on Windows, Ubuntu, and macOS.
- 100 independent core smoke runs with 0 observed failures.
- Complete intentional-failure evidence packages with screenshots, Playwright
  traces, logs, metadata, selectors, and Allure-compatible results.
- Artifact credential scanning and cleanup validation.
- SQLite integrity checks, analytics schema versioning, safe corruption errors,
  90-day retention verification, concurrent queries, and zero-data-loss upgrade
  evidence from a v0.3.3-compatible 1,500-row database.

## Compatibility

Both historical binaries, `prova` and `qe-tool`, remain available. Existing
v0.3.x `run` options are retained and new evidence validation is opt-in or CI
oriented.

## Known limitation

The v0.3.2 BrowserStack campaign remains valid historical evidence, but it is
not proof of the v0.3.4 release commit. A credentialed BrowserStack workflow
must be run before claiming current-code real-device regression coverage.
