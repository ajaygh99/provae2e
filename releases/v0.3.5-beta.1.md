# PROVA v0.3.5-beta.1 — Phase 4 Beta

This beta completes the Phase 4 productization contracts while keeping local,
token-free validation as the default. Package publication remains a separate,
explicitly approved release operation.

## Highlights

- **Studio and Figma:** bounded workspace and design ingestion, safe generation,
  deterministic validation, and clearer operator failures.
- **Performance:** repeatable scenario validation, thresholds, reports, and
  evidence contracts.
- **Security:** bounded ZAP ingestion, risk-policy enforcement, atomic database
  persistence, reports, CLI commands, and CI gates.
- **Analytics:** completed dashboards, filters, exports, integrity checks, and
  deterministic trend validation.
- **Native mobile:** local Appium proof, bounded provider adapters, artifact
  contracts, and explicit credential-gated device-cloud execution.
- **Integrations:** hardened GitHub, Jira, Slack, and Figma contracts with
  redaction, bounded retries, and token-free fixtures.

## Validation model

The repository provides deterministic PowerShell and Jest gates that require no
GitHub, Jira, Slack, Figma, BrowserStack, Sauce Labs, ZAP service, or LLM token.
They validate local behavior, schemas, redaction, failure handling, and package
contracts. They do not claim that live third-party services accepted a request.

Credentialed provider workflows remain opt-in and must capture evidence against
the exact release commit before any live-provider claim is made.

## Compatibility

The package and CLI report `0.3.5-beta.1`. Existing `prova` and `qe-tool`
entrypoints remain available, and new workflows are additive or explicitly
opt-in.
