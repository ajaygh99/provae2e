# PROVA v0.3.3-beta.1 — Analytics Core

This beta adds persistent test analytics without changing existing test execution defaults.

## Highlights

- Opt-in analytics persistence through `--persist-analytics`.
- Zero-configuration SQLite storage and PostgreSQL support through `DATABASE_URL`.
- 90-day default retention.
- 7/30/90-day pass, failure, skip, duration, and flakiness trends.
- Duration and failure-rate anomaly detection.
- Flaky-test ranking.
- Self-contained HTML and machine-readable JSON analytics reports.

## Validation

- Full TypeScript, lint, tests, global coverage, Studio, build, and LENS checks passed on PR #228.
- PostgreSQL 16 service integration passed.
- 10,000-row SQLite trend query met the under-100ms target.
- Labelled anomaly fixtures exceeded 85% precision and recall.

## Deferred feature

Power BI export is feature-flagged off and hidden from the CLI for this release. Its isolated implementation and skipped transport fixtures remain for the credentialed v0.3.3.1 Phase 2 release.

## Compatibility

There are no breaking changes. Analytics persistence is disabled unless `--persist-analytics` is supplied.
