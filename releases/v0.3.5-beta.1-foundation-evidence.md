Date: 2026-07-28

## Scope

- Chromium, Firefox, and WebKit execution with Chromium as the default.
- Safe OpenAPI 3.x execution with write operations disabled by default.
- SQLite selector-healing memory with confidence promotion and decay.
- Default learned-selector reuse threshold of 95%.
- Deterministic candidate ranking with bounded, sanitized fingerprints.
- Optional local Ollama resolution for ambiguous candidates.
- Human approval, rejection, rollback, listing, and clear controls.
- Credential, email, SSN, and payment-card filtering before persistence.
- Provider-neutral AI call and cost budgets.

## Safety decisions

- Adaptive discovery is opt-in.
- No full DOM or trace is sent to a model.
- Ollama receives at most five compact candidate summaries.
- Low-confidence model output is rejected.
- Learned selector reuse and local ambiguity selection default to 95%.
- Test source is never rewritten during execution.
- API writes require explicit `--allow-write`.
- Rollback removes the corresponding selector from local learning memory.
- Sensitive learning records are rejected, not merely masked in SQLite.

## Known limitation

BrowserStack credentialed validation remains unavailable in the local
environment and is recorded as `VALIDATION_GAP_CREDENTIALS_UNAVAILABLE`.
