# PROVA v0.3.1-beta.0 — Beta Reliability and Security

This Beta build resolves the issues identified during the Mnemox and cross-check validation:

- Accepts comma-separated device aliases such as `iphone14,pixel7` and validates each device independently.
- Runs browser and mobile checks with real worker concurrency.
- Applies smoke/full scope consistently across browser and mobile testing.
- Writes immutable per-run reports, screenshots, and performance evidence.
- Treats Chrome Web Store URLs as listing checks instead of claiming extension installation.
- Adds Playwright browser-install and mobile-emulation troubleshooting guidance.
- Migrates the test toolchain to Jest 30 with SWC and V8 coverage.
- Removes known root and Studio dependency vulnerabilities.
- Replaces the vulnerable Studio router dependency with a small same-origin router.

Quality gates: 113 root suites (2,062 tests), 60 Studio tests, TypeScript, lint, production builds, 80% global coverage, package dry-run, smoke checks, and zero known npm audit vulnerabilities.
