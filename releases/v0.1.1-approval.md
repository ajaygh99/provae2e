## What's shipping
This is the first-ever publish of `@provae2e/cli` to npm. Note: the release
pipeline always publishes the *next* patch version above whatever is in
package.json (currently 0.1.0), so this first release ships as **v0.1.1**,
not v0.1.0. Confirmed via `scripts/check-release-approval.js`.
