Effective date: August 9, 2026

## Trademark claim

Ajay claims **PROVAE2E™** as a trademark for the downloadable quality-engineering
software and related software services described in this repository.

The ™ symbol records a common-law trademark claim. It does not represent a
USPTO registration, and the ® symbol must not be used unless registration is
granted.

## Dated evidence

The public evidence of use includes:

- This Git repository and its dated commit and release history.
- The `@provae2e/cli` npm package and its publication history.
- The product documentation and, once the domain is live, dated PROVAE2E
  website captures.
- Dated product screenshots, customer materials, invoices, and announcements
  retained privately by the owner.

Keep private evidence in a secure, backed-up location. Do not commit customer
data, credentials, invoices, or confidential evidence to this repository.

## Copyright and licensing boundary

The source code in this repository remains available under the MIT License.
The copyright notice in `LICENSE` is unchanged. Adding a trademark claim does
not remove or restrict permissions already granted under MIT.

Copyright protects qualifying human-authored expression automatically. It does
not protect product ideas, algorithms, methods, or purely AI-generated output.
Maintain Git history and written IP assignments from every employee or
contractor who contributes code, designs, documentation, or branding.

Any proprietary PROVA Growth OS implementation should be created in a separate
private repository with a commercial license. Do not copy an "All rights
reserved" notice into this MIT repository because that would create an unclear
licensing message.

## Registration review

Review federal registration on or after August 9, 2027:

1. Run a professional clearance search for PROVAE2E and related marks.
2. Decide whether to file the PROVAE2E word mark in Class 9.
3. Assess Class 42 based on actual SaaS use.
4. Consider registering the logo separately only after consistent commercial
   use and revenue.

This record documents operational steps; it is not legal advice.
